# 場所カテゴリの表示・編集・タイプフィルタ

## 目的

Google Places 由来の英語カテゴリ (`resort_hotel` 等) がそのまま画面に出るのをやめ、
日本語で読める表示に統一する。さらに利用者がカテゴリを選び直せるようにし、
地図画面ではタイプで場所を絞り込めるようにする。

## 表示ラベル

- `placeTypeLabel(category)` を唯一の表示変換とする。
  - 空/空白のみ → `未分類`
  - 既知の英語カテゴリ → 対応する日本語ラベル (完全一致 → 小文字化して再照合)
  - それ以外 → 前後の空白を除いた入力値をそのまま返す
- 変換表は継承プロパティを拾わない (`constructor` 等の入力でも文字列を返す)。
- 表示するすべての箇所 (場所詳細、場所一覧、ライブラリ、旅のしおり、地図の情報窓、
  地図検索結果) は生の `category` ではなくこのラベルを使う。
- 一覧の絞り込み検索も、生の値ではなく表示ラベルを対象にする。

## 編集

- 場所詳細でカテゴリをセレクトから変更できる。選択肢は既定の日本語カテゴリ一覧と `未分類`。
- 現在値が既定一覧に無い場合 (自由入力の既存データ等) は、その値を選択肢の先頭に追加して保持する。
- 表示中の値は `normalizedPlaceCategory()` = 表示ラベル (ただし `未分類` は空文字) を使う。
  よって英語カテゴリの場所を保存し直すと、`places.category` は日本語ラベルへ置き換わる。
- 保存は `PATCH /api/places/:id` の `category` (空選択は `null`)。保存中はセレクトを無効化し、
  成否のメッセージをセレクト直下に表示する (失敗はエラー表示)。
- 保存に失敗した場合はセレクトの表示を保存済みの値へ戻す (未保存の値を残さない)。
- 保存後は場所を再読込し、呼び出し元 (旅の一覧/地図) にも変更を通知する。

## タイプフィルタ (地図画面)

- 対象は「また今度」でない場所。表示ラベルの集合を日本語順に並べて選択肢にする。
- フィルタは地図上部の拠点バーに置いたポップオーバーで開閉する。
  トリガーには選択件数 (`すべてのタイプ` / `タイプ N件`) を表示する。
  地図が表示できない間 (APIキー未設定/読込中/エラー) は、同じフィルタを場所一覧側に出す
  (フィルタは一覧の絞り込みも兼ねるため、地図の可否で使えなくならないようにする)。
- ポップオーバーは背景タップまたは Esc で閉じる。
- 複数選択 (トグル) で、選択が 1 件以上なら該当タイプのみを一覧・ピン・全体表示に反映する。
- 場所の増減で選択肢から消えたタイプは、選択状態からも自動的に外す。
  タイプが 0 件になった場合はポップオーバーを閉じ、フィルタ自体を描画しない。

## 制約・既知の制限

- カテゴリは自由文字列のまま保存される (サーバ側で既定一覧に制限しない)。
- 変換は表示側のみで、既存の `places.category` を一括変換する移行は行わない。
